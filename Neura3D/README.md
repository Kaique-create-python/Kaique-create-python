# Neura3D Studio

Android 3D modeling editor prototype built with native OpenGL ES.

Features in v0.1:
- 3D viewport with orbit and pinch zoom
- Cube, sphere and cylinder primitives
- Tap selection
- Move, rotate and uniform scale modes
- Duplicate/delete
- Undo/redo
- Internal project save/load
- OBJ export through Android document picker
- Grid and XYZ selection gizmo

This branch is used to build the APK artifact.
