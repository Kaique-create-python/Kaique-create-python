## Task 2 — Preferências e mobile
Schema Preferencias17 compartilhado; novo módulo servidor persistente com remote validado e patches limitados; cliente carrega/aplica após inscrição; editor de layout por botão com drag/scale/cancel/reset/commit e regiões seguras. Controles preservam Toques. Menu integra ajustes salvos/editor. HUD mostra estados reais. RED: payloads malformados, save/load/race, layout em 844x390 e 667x375, cancel não altera salvo. GREEN: testes de política e integração.

## Task 3 — Treino
Política Treino17 + integração Bots/Combate/Main; boneco de laboratório próprio por jogador, respostas após hit e somente quando regras permitirem. Painel cliente e relatório servidor. Reset só de cenário próprio e sem restaurar cooldown de PvP. RED: outro dono, menu/respawn/saída, janela de stun, reset rate/fora treino; GREEN: testes reais.

## Task 4 — Visual, integração e entrega
Perfil de iluminação refinado, limites de legibilidade nos efeitos sem alterar dano; AJ17 aceita hashes14/15/16 e preserva resto do Place. Nova confirmação/estado17, não apagar active-write de revisões anteriores. Build determinístico, instalador autocontido, teste Saved atualizado cobre novas fontes. Rodar suíte completa, revisão independente única, corrigir achados importantes com teste, entregar via GitHub + comandos curtos.

## Interfaces / review focus
Preferências: schema puro->servidor->remote->cliente->Menu/Controles. Treino: Combate comunica resultado ao serviço sem dependência circular; Bots recebe alvo/dono explícito. Cronologia: o mesmo início do servidor para todos; local previsto não reposicionado no ACK. Nenhuma função cliente concede dano ou poderes de treino. Falha ao carregar configurações não sobrescreve remoto. Mapa e mídias intocados. Checar input capturado durante editor, geometria safe-area, cleanup/reentrada e saves simultâneos.
